# Treino Academia (PWA)

Aplicativo web progressivo (PWA) para geração e acompanhamento de treinos personalizados usando apenas o peso corporal, projetado com interface mobile-first de alta energia (dark mode esportivo).

---

## ⚡ Recursos
- **100% Client-Side**: Não requer servidor ou backend.
- **Suporte Offline**: Totalmente funcional offline após o primeiro acesso via Service Worker.
- **Customização de Treinos**: Filtros por Duração (10 a 45 min), Nível (Iniciante, Intermediário, Avançado) e Foco Muscular (Corpo Inteiro, Superiores, Core, Inferiores).
- **Player Ativo Interativo**: Controles de treino com cronômetro circular animado para exercícios e descansos.
- **Histórico Local**: Salva treinos concluídos no `localStorage` do dispositivo.
